## 🌐 アプリの表示言語を切り替える方法（22 言語対応）

1. **NidoOffice** を開き、ホーム画面左下の **設定（`⚙️` / Settings）** アイコンをクリックします（または `Cmd + ,` / `Ctrl + ,`）。
2. **一般（General）** タブの **言語（Language）** を選択します。
3. **日本語** または希望する言語を選択すると、再起動なしで即座に切り替わります。
