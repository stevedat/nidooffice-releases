**NidoOffice** — высокопроизводительный настольный офисный пакет с приоритетом локальной обработки данных (**Local-First**) для **macOS, Windows 10/11 и Linux**. Поддерживает **Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), PDF (с локальным OCR), Markdown (`.md`) и HTML**.

## 🌐 Как переключить язык интерфейса в приложении (22 языка)

1. Откройте **NidoOffice** и нажмите на значок **Настройки (`⚙️` / Settings)** в левом нижнем углу (или нажмите `Cmd + ,` / `Ctrl + ,`).
2. На вкладке **Общие (General)** выберите пункт **Язык (Language)**.
3. Выберите **Русский** или любой другой язык — интерфейс обновится мгновенно без перезапуска.
