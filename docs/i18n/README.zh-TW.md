## 🌐 如何切換應用程式介面語言（支援 22 種語言）

1. 開啟 **NidoOffice**，點擊左下角 **設定（`⚙️` / Settings）** 圖示（或按 `Cmd + ,` / `Ctrl + ,`）。
2. 在 **一般（General）** 分頁中找到 **語言（Language）**。
3. 選擇 **繁體中文** 或所需的語言，介面將立即切換。
