**NidoOffice** est une suite bureautique de bureau haute performance (**Local-First**) pour **macOS, Windows 10/11 et Linux**, prenant en charge nativement **Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), PDF (avec OCR local), Markdown (`.md`) et HTML**.

## 🌐 Changer la Langue de l'Application (22 Langues)

1. Ouvrez **NidoOffice** et cliquez sur l'icône **Paramètres (`⚙️` / Settings)** en bas à gauche (ou appuyez sur `Cmd + ,` / `Ctrl + ,`).
2. Dans l'onglet **Général (General)**, sélectionnez **Langue (Language)**.
3. Choisissez **Français** ou la langue souhaitée : l'interface se met à jour immédiatement sans redémarrage.
