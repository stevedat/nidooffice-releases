**NidoOffice** ist eine leistungsstarke **Local-First** Desktop-Office-Suite für **macOS, Windows 10/11 und Linux** zur nativen Bearbeitung von **Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), PDF (mit lokaler OCR), Markdown (`.md`) und HTML**.

## 🌐 Sprache der Benutzeroberfläche ändern (22 Sprachen)

1. Öffnen Sie **NidoOffice** und klicken Sie unten links auf **Einstellungen (`⚙️` / Settings)** (oder drücken Sie `Cmd + ,` / `Ctrl + ,`).
2. Wählen Sie im Reiter **Allgemein (General)** die Option **Sprache (Language)**.
3. Wählen Sie **Deutsch** oder Ihre bevorzugte Sprache — die Oberfläche wird sofort ohne Neustart umgestellt.
