**NidoOffice** é uma suíte office desktop de alto desempenho (**Local-First**) para **macOS, Windows 10/11 e Linux**, com suporte nativo para **Word (`.docx`), Excel (`.xlsx`), PowerPoint (`.pptx`), PDF (com OCR local), Markdown (`.md`) e HTML**.

## 🌐 Como Alterar o Idioma do Aplicativo (22 Idiomas)

1. Abra o **NidoOffice** e clique no ícone **Configurações (`⚙️` / Settings)** no canto inferior esquerdo (ou pressione `Cmd + ,` / `Ctrl + ,`).
2. Na aba **Geral (General)**, selecione **Idioma (Language)**.
3. Escolha **Português (Brasil)** ou o idioma desejado — a interface muda instantaneamente sem reiniciar.
